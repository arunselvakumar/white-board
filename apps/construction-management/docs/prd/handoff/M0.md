## Spec changes

- **CM-001:** "schemas in the shared database" → schemas in the app's **own** `construction` database, sharing `packages/db`'s one Prisma schema and migration history (so Whiteboard's empty schemas exist there and vice versa). Matches `03-target-architecture.md §1` ("one database `construction`") and CM-003/CM-006.
- **CM-003:** local S3 is SeaweedFS, not MinIO — MinIO's Docker images are no longer pullable. It accepts any access key; the app creates its bucket on first use.
- **CM-007:** the Vercel project is an owner step (see below).
- **CM-009:** `/sign-in` and `/sign-up` are headings only; their forms are CM-103.
- HTTP test database variable is `CONSTRUCTION_DATABASE_URL_TEST` (CI exports Whiteboard's `DATABASE_URL_TEST` globally).

## Stubs left for later milestones

- Sign-in / sign-up forms, Company creation and the Company switcher — M1 (CM-103, CM-104, CM-105). The header shows the Active Company's name only.
- Every route is owner-only until the Permission Matrix (CM-107).
- `Money` is a JS number of paise (safe to ±₹90 lakh crore). Amount columns will need `BigInt` in Postgres once ledgers exist (M2); decide the Prisma mapping then.
- Product name and logo: "Construction Management" with a hard-hat mark until there is a brand.

## How to run and verify

```sh
docker compose up -d
docker compose exec postgres psql -U whiteboard -c "CREATE DATABASE construction"   # existing volumes only
cp apps/construction-management/.env.example apps/construction-management/.env       # fill BETTER_AUTH_SECRET
DATABASE_URL=postgresql://whiteboard:whiteboard@localhost:5433/construction bun run --filter @repo/db migrate:deploy
bun run dev --filter=construction-management      # :3002, /api/docs
bun run --cwd apps/construction-management test
bun run --cwd apps/construction-management test:http
bun run --cwd apps/construction-management test-storybook
```
