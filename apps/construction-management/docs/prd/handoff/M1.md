## Owner decisions taken during M1

- **Greenfield:** customers start fresh; no BuildControl import, ids or "legacy" wording in code (`03-target-architecture.md §4` marked not planned).
- **Better Auth scope:** Better Auth keeps identity, sessions, mobile OTP and `owner`/`member` membership; the Permission Matrix and Join Requests stay in the organization context (ADR CM-0003, considered options).
- **Files in Vercel Blob, not S3** (ADR CM-0001, architecture §1).

## Spec changes

- CM-101/109: Join Requests are Team Member records matched by verified mobile/email, not Better Auth invitations (email-only).
- CM-106: the Designation list is 38 names, not 37; templates are our defaults per role.
- CM-107: grants are keyed by Team Member (`memberId`), not User, so a Joining Pending member has a matrix.
- CM-108: a Team Member needs a mobile **or** an email (not both); Aadhaar is checked by its Verhoeff digit.
- CM-112–118: see the "Delivered" / "Decided while building it" notes under each ticket in `milestones-and-tasks.md`; `modules/12` open questions 1, 2, 3, 7, 12 and `modules/01` open questions 7–9 now record answers.
- CM-118: error codes are `PLAN_LIMIT_EXCEEDED` / `PLAN_EXPIRED` (HTTP 402), upper case like every other code.

## Stubs left for later milestones

- **Projects** (CM-204): the wizard's Select Projects step and the edit tab show an empty state; project ids are stored but unchecked; the plan counts 0 projects (`NO_PROJECTS` in `prisma-usage-reader.ts`); the Sequence IDs screen offers only "All projects".
- **OTP before reveal** of Aadhaar/PAN (others' and your own): M9. Today reveal is Owner-only (others) and logged.
- **SMS invitations** in production need a DLT-approved MSG91 template (`MSG91_INVITE_TEMPLATE_ID`); until then invites go by email and by "Share invite link".
- **Changing a User's sign-in email** is not built (My Profile edits the Team Member contact email only).
- No auto-renew; only the Basic plan exists (upgrade is tested with a made-up plan).
- UI does not yet hide actions a Member lacks; the API refuses them with `PERMISSION_DENIED`.

## How to run and verify

```sh
docker compose up -d
cp apps/construction-management/.env.example apps/construction-management/.env   # fill BETTER_AUTH_SECRET, CONSTRUCTION_PRIVATE_DATA_KEY; OTP_TEST_CODE=000000 for dev
DATABASE_URL=postgresql://whiteboard:whiteboard@localhost:5433/construction bun run --filter @repo/db migrate:deploy
bun run dev --filter=construction-management    # :3002 — sign in with any +91 mobile; the code prints in the server log
bun run --cwd apps/construction-management test            # 142 unit
bun run --cwd apps/construction-management test:http       # 108 on construction_test
bun run --cwd apps/construction-management test-storybook  # 87 stories
```

Verified in Chrome on the dev server: mobile sign-in → Choose Company → shell with trial banner; Create Company (38 Designations seeded); Add Team Member wizard with the Admin template → invite and share link; Designations list; Back-dated Entry; Sequence IDs; Company profile with logo upload and stream-back; My Profile; Your Subscription (Team Members 2 of 5, 14 days left).
