# Urbanist at 300 / 400 / 600

v2’s production type is Quicksand (body 500, headings 700). v3 uses Urbanist on both Whiteboard and the Marketing Site: light 300, regular 400, semi-bold 600 only. Urbanist reads larger and cleaner, so the extra weights are unused. Tokens live in `packages/ui`; both apps consume them.
