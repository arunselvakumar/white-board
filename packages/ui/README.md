# `@repo/ui`

Shared shadcn/ui components, Tailwind CSS theme, and helpers.

```ts
import { Button } from "@repo/ui/components/button";
import { Card } from "@repo/ui/components/card";
import { cn } from "@repo/ui/lib/utils";
```

Add more components from an app:

```sh
bunx --bun shadcn@latest add card -c apps/whiteboard
```
