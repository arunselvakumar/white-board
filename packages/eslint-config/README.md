# `@repo/eslint-config`

Strict shared ESLint configs:

- `@repo/eslint-config/base` — TypeScript `strictTypeChecked` + `stylisticTypeChecked`
- `@repo/eslint-config/next-js` — Next.js, React, React Hooks, and `jsx-a11y`
- `@repo/eslint-config/react-internal` — React libraries, with `jsx-a11y`

All packages run ESLint with `--max-warnings 0`.
