# `@repo/eslint-config`

Strict shared ESLint configs:

- `@repo/eslint-config/base` — TypeScript `strictTypeChecked` + `stylisticTypeChecked`
- `@repo/eslint-config/next-js` — Next.js, React, and React Hooks
- `@repo/eslint-config/react-internal` — React libraries

All packages run ESLint with `--max-warnings 0`.
